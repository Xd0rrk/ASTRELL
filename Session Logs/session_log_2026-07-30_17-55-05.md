## Important Decisions & Reasoning
1. **Bento Grid for Mobile (`grid-cols-2`)**:
   - *Reasoning*: A 1-column stack required mobile users to scroll through 4 full-height cards. A 2-column Bento Grid presents all 4 stats simultaneously in a visually rich visual block.
2. **Distinct CSS Variable Names (`--font-inter` vs `--font-sans`)**:
   - *Reasoning*: Setting `--font-sans: var(--font-sans)` inside CSS creates a circular definition according to CSS Specs, causing browsers to invalidate the property and default to Times New Roman. Using separate variable names (`--font-inter` assigned to `--font-sans`) resolves the cycle completely.
