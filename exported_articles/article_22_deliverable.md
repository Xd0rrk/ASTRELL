**2. The Anatomy of a Micro-Interaction**
- Trigger (User action or system event).
- Rules (What happens?).
- Feedback (The visual/audio response).
- Loops & Modes (What happens next?).

**3. The Psychology of Spring Physics**
- Why standard CSS cubic-bezier curves often feel "robotic."
- Introducing mass, stiffness, and damping to create UI elements that feel like physical objects under glass.

**4. Implementing Motion at Scale (Framer Motion)**
- Moving beyond simple CSS transitions to state-driven React animation.
- Managing layout animations and drag-and-drop physics with Framer Motion.

**5. Performance and Accessibility Rules**
- Keeping interactions under 300ms to avoid sluggishness.
- Respecting the `prefers-reduced-motion` media query to prevent user nausea and ensure WCAG compliance.
